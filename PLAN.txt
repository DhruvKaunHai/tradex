3. HOW IT WILL BE BUILT
-----------------------
Two parts, because the broker API key must stay secret and cannot sit in browser code.

Server (Node.js) - hosted on Render
  - Downloads 5 min candles from 1 Jan 2024 from the broker, month by month, and saves them.
  - Builds the 15 min and 30 min candles from the 5 min ones, so all three always agree.
  - Connects to the broker live feed, forms the running candle and pushes it to the browser.
  - Fills any gap on its own after a restart or a network drop.
  - Holds the API key and token. They never go to the browser or to GitHub.

Website (plain HTML, CSS, JavaScript) - hosted on Cloudflare Pages
  - Landing page, chart workspace, Pine editor, strategy tester, reports.
  - The backtest runs in your browser in a background worker, so the page does not freeze.
  - Charts drawn with Lightweight Charts, the open-source chart library (free licence).

Code goes to one GitHub repository. Cloudflare and Render both deploy from it.
A DEPLOY.txt will give the exact steps.

6. PINE SUPPORT - PLEASE READ
-----------------------------
Pine Script belongs to TradingView and its engine is not public. So TradeX will have its own
engine that reads Pine v5 / v6 style code. It will cover what strategies normally use:
  - strategy(), indicator(), input.*, variables, var, if / else, for, while, functions, arrays (basic)
  - series history like close[1], na handling, math.*
  - ta.* : sma, ema, rma, wma, vwma, rsi, macd, atr, bollinger, stochastic, supertrend, vwap,
           highest, lowest, crossover, crossunder, change, pivots and more
  - strategy.entry, strategy.exit (stop, limit, trailing), strategy.close, strategy.close_all,
    position size, pyramiding, commission, slippage
  - time, hour, minute, session checks (useful for intraday square-off)
  - plot, plotshape, hline, bgcolor, fill (drawn on the chart)
Not covered in the first version: request.security (other symbols / timeframes), tables, labels and
boxes with full styling, libraries, matrix and map types. If a script uses something unsupported,
the editor will say exactly which line and which function. It will not silently give a wrong result.
Most TradingView strategies will paste and run. I cannot promise every script will.


7. STRATEGY REPORT (more detail than TradingView)
-------------------------------------------------
  - Net profit, gross profit / loss, profit factor, win rate, expectancy, average win / loss, payoff ratio
  - Max drawdown (amount, %, duration, recovery time), equity curve with drawdown shading
  - Sharpe, Sortino, Calmar, CAGR
  - Long and short shown separately
  - Month-by-month and year-by-year profit grid
  - Results by day of week, by time of day and by expiry day
  - Winning and losing streaks, trade duration spread, profit distribution chart
  - Best and worst trade and day, run-up and drawdown inside each trade (MAE / MFE)
  - Buy-and-hold comparison for the same period
  - Monte Carlo reshuffle of trades to show how much of the result is luck
All charts in the report are interactive (hover, zoom, click to jump to the chart).
